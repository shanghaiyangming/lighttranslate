# 我用 Codex 做了一个 Windows 划词翻译工具，现在把它开源了

阅读英文网页、技术文档时，最让我分心的不是某个词不认识，而是来回操作：选中文字、复制、切到聊天窗口、输入翻译要求，再切回原页面。

所以我用 Codex 做了一个很小的 Windows 工具，叫 **轻译**。它想解决的事情很简单：**选中文字，按一下快捷键，译文就出现在鼠标旁。**

![轻译翻译场景](media/translation-demo.png)

## 它怎么用？

从 GitHub 下载 Windows 安装包或便携 EXE，首次启动填写自己的 DeepSeek API Key。默认接口和模型已经填好，保存后，在支持复制的应用里选中文字，按 `Ctrl+Alt+Q` 即可。

译文流式显示，点击外部或按 Esc 收起。浮窗可以复制结果、停止、重试、粘贴文字，也能查看和编辑原文。程序收起后在托盘运行，快捷键和开机启动可以自己设置。

## 翻译，也能查词

较长文本默认译为简体中文。英文单词和简短词组则进入查词候选模式，给出音标、中文解释、用法、例句与词源。显示支持常见 Markdown 标题、加粗、列表和代码格式。

![轻译查词场景](media/dictionary-demo.png)

音标和词源由模型生成，可能不准确；它也不处理图片 OCR。轻译目前更适合“快速理解一段可复制文字”，而不是替代权威辞典或完整文档翻译系统。

## 密钥与费用

软件免费，API 由服务商向使用者自己的账号按量计费。密钥使用 Windows 当前用户 DPAPI 加密保存。原文直接发给使用者配置的 API 服务商，没有项目运营的中转服务器，不保存翻译历史。

演示素材使用真实桌面界面和本地模拟接口，阅读选区步骤为场景说明，不是 DeepSeek 响应速度测试，也没有用到真实密钥。

## 开源与下载
