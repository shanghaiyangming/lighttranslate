25 秒，看看它怎么用

浮窗采集自实际程序；选区步骤为场景示意，响应来自本地模拟接口，不是 DeepSeek 速度实测。制作说明

少一点来回切换

全局快捷键、鼠标旁浮窗、流式显示，支持复制、停止、重试和手动粘贴。

翻译，也能查词

长文本默认译成中文；短英语候选提供 IPA、释义、用法、例句及词源。

用自己的 Key

密钥由 Windows 当前用户加密保存在本机；原文直接发给你设置的 API 服务商。

第一次使用，三步开始

  1. 下载安装版，或运行便携 EXE。
  2. 首次设置填入自己的 DeepSeek API Key，保留 https://api.deepseek.com 和 deepseek-flash。
  3. 在支持复制的应用中选中文字，按 Ctrl+Alt+Q 后松开。
