## 英文简介（粘贴到英文站）

LightTranslate (轻译) is a free, open-source (MIT) Windows selection translator and English dictionary. Select copyable text in any app, press Ctrl+Alt+Q, and a small popup beside the cursor streams a Simplified Chinese translation. Short English words or phrases can also show IPA, meaning, usage and examples. It runs in the system tray, supports configurable hotkeys, copy/cancel/retry/paste, and uses the user's own DeepSeek API key (stored locally with Windows DPAPI; no translation history saved; no OCR). Requires Windows 10/11 x64 and .NET Framework 4.8.

Homepage/demo: https://shanghaiyangming.github.io/lighttranslate/
