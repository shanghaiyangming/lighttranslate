## 完整介绍

平时读英文网页和文档，复制文字、切到聊天窗口、输入翻译要求，再切回原页面，来回操作很打断思路。所以我用 Codex 做了「轻译」。

用法很简单：选中文字 → Ctrl+Alt+Q → 看鼠标旁的译文。长文本译成中文，英文单词和 1–5 词短语可以查音标、中文含义、用法、例句和词源。结果流式显示，也能复制、停止和重新翻译。

我已经把它以 MIT 许可证开源，并提供 Windows x64 安装包和便携 EXE。第一次启动填入自己的 DeepSeek API Key 即可；软件免费，API 由服务商按用量计费。密钥使用 Windows 当前用户加密保存在本机，翻译文本直接发给自己设置的 API 服务商，没有项目中转服务器。

它适合想让日常阅读少一点切换操作的人。欢迎试用、Star 和提建议。模型生成的音标及词源也可能有误，欢迎一起改进。
